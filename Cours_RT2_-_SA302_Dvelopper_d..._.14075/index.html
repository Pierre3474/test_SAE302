Résumé du cours

Descriptif générique :
  Partant de l’analyse d’un cahier des charges fourni, le professionnel R&T développe une application communicante permettant l’échange et la sauvegarde de données. La réalisation de ce projet contient les étapes suivantes :
  – Analyser le cahier des charges fourni et répondre à celui-ci en mentionnant les technologies à utiliser et éventuellement leur impact environnemental et économique ;
  – Développer une application client/serveur ;
  – Authentifier les utilisateurs ;
  – Sauvegarder les données échangées ;
  – Concevoir une interface graphique, une application mobile ou une interface Web.

Séances: 1 CM, 10 E, 14 NE, 4 TP

Séances App: 5 E, 7 NE, 3 TP



Cahier des charges

Application client/serveur de gestion de certificats

L'application client/serveur sera écrite en python (sans FRAMEWORK) fonctionnera en TCP sur le port 7890.

  1.     Développer des outils en ligne de commande
  2.     Authentifier les utilisateurs
  3.     Sauvegarder les données échangées

But:
  •     Création/vérification/renouvellement/révocation de certficats.
  •     Un utilisateur peut gérer entièrement une ou plusieurs PKI (Public Key Infrastructure).
  •     L'administrateur possède tous les droits. Il peut créer des utilisateurs et leur affecter la gestion d'une PKI, changer les mots de passe, bloquer certains comptes, etc...

Fonctionnalités obligatoires:

  •     Application serveur "multi-clients" simultanés
  •     Notions de droits pour les utilisateurs (role administrateur, éditeur, vérificateur...)
  •     Stockage de tous les évènements (authentification, commandes, erreurs, ...) dans un fichier de traces horodaté.

En option, on pourra :

  •     Revenir en arrière pour annuler une commande passée par erreur.
  •     Chiffrer les échanges de données (TLS).
  •     Utiliser IPv6 et/ou IPv4 pour se connecter au serveur.
  •     Concevoir une interface graphique, une application mobile ou une interface Web.

Exemples d'utilisation du client:

pkicli -H mypki.rtbz.fr -u admin -p
password: ***********

pkicli# help
pkicli# users list
pkicli# users disable alice
pkicli# users enable john
pkicli# users create bob XXXX
pkicli# users infos bob

pkicli# pki list
pkicli# pki add ca1 /C=fr/O=SAE302/CN=CA1 RSA 4096 enc
pkicli# pki delete ca15
pkicli# pki infos ca1
pkicli# pki update ca1
pkicli[ca1]# rename ca2
pkicli[ca2]# list crt
pkicli[ca2]# revoke key18
pkicli[ca2]# crlgen 90
pkicli[ca2]# bye

pkicli# users update bob
pkicli(bob)# pki list
pkicli(bob)# add ca2,ca3
pkicli(bob)# delete ca3
pkicli(bob)# passwd YYYY
pkicli(bob)# bye
pkicli# bye
