Séance 1 :

1-Utiliser l'outil nc pour se connecter au serveur 10.42.227.111 sur le port 4567.
2-Vérifier que le serveur suit bien le protocole ci-dessous:
  client               serveur
  <---- Server Hello    -----
  ----- Client name     ---->
  <---- Server response -----
3-Ecrire ensuite un client en python.
4-Comment afficher les valeurs @ip+port source et destination ?
5-Comment indiquer le message envoyé par le client sur la ligne de commandes ?
6-Comment le demander au clavier s'il n'est pas fourni ?
7-Comment ne pas afficher les caractères dans la console quand on tape le message du client ?
8-Ecrire maintenant le serveur (en version multi-clients simultanés)...
9-Comment écrire alors un nouveau client/serveur supportant le protocole suivant
  avec des identifiants fixes au niveau du serveur (user=toto;pwd=titi):
  client               serveur
  <---- Server AUTH     -----
  ----- Client USER     ---->
  ----- Client PWD      ---->
  <---- Server response -----
10-Comment utiliser plutôt un fichier texte d'utilisateurs (lignes au format: user:pwd) ?
11-Comment utiliser un fichier texte d'utilisateurs plus sécurisé (lignes au format: user:sha1(pwd)) ?

  Peut-on toujours utiliser la base d'utilisateurs avec des mots de passe hachés ?

  <---- Server CHALL    -----
  ----- Client USER     ---->
  ----- Client PWDHASH  ---->
  <---- Server response -----
